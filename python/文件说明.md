# python 文件说明

本目录为平铺结构，每种主要文件只保留一份；无测试脚本、字节码缓存或历史代码副本。

| 文件 | 主要内容 |
| --- | --- |
| `run_latest_experiment.py` | 主运行入口。选择最新有效北斗三号 TLE，生成本次配置，依次启动 STK 几何生成、MATLAB 信道计算和结果绘图。默认搜索北京时间当天最早可用片段。 |
| `tle_sync.py` | 下载并校验北斗三号 TLE；保存到同级 tle 文件夹；--latest 只读取最新本地有效快照。 |
| `generate_covered_scene.py` | 调用 STK Engine/Desktop 建立卫星、飞行器和波束，搜索连续覆盖，导出几何时序 CSV、元数据和搜索记录。内部保留覆盖、时间网格和运动连续性检查。 |
| `plot_results.py` | 读取同一 run_id 的几何与信道 CSV，生成覆盖/运动和增益/CSI 图，写入 stk 文件夹。默认读取随附成功样例。 |
| `project_paths.py` | 统一解析整理后目录及运行配置，确保工作脚本使用本文件夹内的数据；NTN_CONFIG 可指定另一份配置。 |

推荐在“整理后”目录执行 `D:/Python/python.exe -B python/run_latest_experiment.py`。依赖 NumPy、Matplotlib、已安装的 STK Python API 和可用 STK 许可证。测试、验收专用脚本及报告生成脚本未纳入。
