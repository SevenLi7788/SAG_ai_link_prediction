# matlab 文件说明

本目录为平铺结构，每种主要文件只保留一份；无测试脚本、字节码缓存或历史代码副本。

| 文件 | 主要内容 |
| --- | --- |
| `run_channel_stage.m` | 主信道计算函数。读取 csv 中同 run_id 的几何输入，计算相关 Rician 简化信道、损耗、增益和复 CSI；将 CSV 写回 csv，MAT 写到本目录。已有信道 CSV 时停止，避免覆盖。 |
| `beidou3_20260924_100355_822022_channel_result.mat` | 最近一次成功实验的 MATLAB 结果原件，包含结果表 result、复信道 h、散射分量 scatter、配置 cfg 和几何元数据 meta。 |

建议由 Python 主入口调用 MATLAB。已有样例可用 MATLAB 的 `load` 打开 MAT 文件查看；直接对默认配置重跑会因输出已存在而停止。MAT 文件内部历史绝对路径保留为溯源记录。
