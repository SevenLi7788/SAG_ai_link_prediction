# csv 文件说明

本目录为平铺结构，每种主要文件只保留一份；无测试脚本、字节码缓存或历史代码副本。

| 文件 | 主要内容 |
| --- | --- |
| `beidou3_20260924_100355_822022_stk_link.csv` | 最近一次成功实验的 STK 几何输入，5001 行；包含时间、卫星/飞行器位置速度、距离、径向速度、多普勒、离轴角及可见/波束覆盖状态。 |
| `beidou3_20260924_100355_822022_channel_result.csv` | 与几何输入逐行配对的 MATLAB 信道结果，5001 行；包含损耗、大尺度/瞬时增益、CSI 实部与虚部。 |
| `beidou3_20260924_100355_822022_metadata.json` | 几何生成元数据：时间范围、样本数、选定卫星、配置、覆盖统计与来源 SHA-256。原样复制，历史路径为生成时的记录。 |
| `beidou3_20260924_100355_822022_channel_metadata.json` | 信道元数据：模型参数、随机种子、MATLAB 版本和有限增益行数等。原样复制。 |

相同 run_id 前缀表示同一次实验。两份 CSV 和元数据内容均与原件完全一致，仅文件名加上实验编号，以便取消子文件夹后仍能区分来源。
